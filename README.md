# Stormwater Intelligence – Environmental Dataset Collection

This repository hosts curated outputs from the **Stormwater Intelligence Program**, focusing on real stormwater, rainfall, and runoff data from Southern California sites.  
Each dataset supports research, compliance automation, and environmental forecasting.

## Available Datasets
| Dataset | Description | Format | Access |
|----------|--------------|---------|--------|
| `rainfall_event_log_2025` | Logged precipitation events with NOAA timestamps | CSV | Public |
| `stormwater_runoff_model_CA` | Simulated runoff and infiltration data | CSV / GeoJSON | By request |
| `epa_storm_compliance_records` | Aggregated discharge and inspection data | CSV | By request |

## Usage
Data may be used for:
- Hydrologic modeling and flood prediction  
- Compliance documentation (EPA, CGP, NPDES)  
- AI/ML training for environmental forecasting
